# OpsFlow

Mini ERP + CRM Operations Portal.

## Project Structure

- `frontend` - React frontend
- `backend` - Node.js + Express backend
- `docs` - Architecture and project documentation
- `postman` - API collection and documentation

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- Prisma
